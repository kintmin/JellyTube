# 마무리 음성을 말로 만들기

상태: 아이디어
다시 보는 조건: 기기에서 돌아가는 음성 합성의 공수와 제약을 알아본 뒤

## 무엇을 하려 했나

잠들기 타이머가 끝날 때 들려줄 말을 **음원 파일 없이 만들어 주는 것.** 기본 문구를 두고
데스크톱에서 바꿀 수 있게 하면, 사용자가 음성 파일을 따로 준비하지 않아도 된다.

## 왜 지금 없나

지금은 **가지고 있는 음원 중에서 고르게** 한다. 쓸 수는 있지만 "잘 자" 같은 말을 들으려면
그 파일을 먼저 만들어 넣어야 한다.

말로 만드는 쪽은 **공수도 제약도 알아보지 않았다.** 플랫폼이 주는 음성 합성을 쓸 수 있는지,
기본 문구를 어느 언어로 둘지, 데스크톱에서 바꾼 문구를 폰으로 어떻게 넘길지 모두 미정이다.

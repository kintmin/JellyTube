# 취향 분석과 곡 추천

상태: 아이디어
다시 보는 조건: 모아 둔 로그로 무엇을 말할 수 있는지 들여다본 뒤

## 무엇을 하려 했나

무엇을 자주 듣는지로 취향을 읽고 곡을 추천하는 것. 패턴 로그를 이미 모으고 있고 받아 온 곡에
딸린 정보도 있으니 **재료는 있다.**

## 왜 지금 없나

**재료가 있다는 것만 알고 제대로 찾아본 적이 없다.** 그 로그로 추천이 될 만한지, 어떤 정보가
더 필요한지 확인하지 않았다.

그리고 들어가는 순간 **동의를 묻는 일이 생긴다.** 지금은 패턴을 모으는 것이 크래시를 보는
것과 한자리에 묶여 있는데, 추천을 위해 모으는 것이라면 **사용자가 켜고 끌 수 있어야 한다.**
비밀 곡을 집계에서 빼는 것과는 다른 층의 문제다 — 그쪽은 숨긴 것을 지키는 일이고, 이쪽은
모으는 것 자체를 고르게 하는 일이다.

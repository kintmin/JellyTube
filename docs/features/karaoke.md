# 노래방 번호

곡에 노래방 번호를 붙여 두고 상세 화면에서 본다.

## 의도된 제약

- **TJ 번호만 다룬다.** 다른 브랜드 번호는 넣지 않았다.
- **번호는 곡마다 하나다.** 여러 브랜드를 함께 들고 있지 않다.
- **사용자가 검색해서 고른다.** 받은 뒤 자동으로 붙이지 않는다 — 노래방에 등록된 곡이
  한정적이라 맞는 번호가 없는 곡이 많다. 곡마다 요청을 하나 더 해도 그렇게 붙는 번호는 적고,
  틀린 번호가 붙으면 노래방에서 다른 곡이 불린다.
- **공식 창구가 없어 공개된 비공식 API 에 의존한다.** 그쪽이 닫히면 검색이 멈추고, 이미 붙여
  둔 번호만 남는다. 대신 번호를 직접 넣는 길이 필요해진다.
- **검색 실패를 오류로 올리지 않는다.** 상세 화면에 들어갈 때와 검색할 때마다 부르기 때문에,
  망이 끊긴 기기에서 같은 실패가 쌓인다. 기록은 남기지만 들여다볼 오류로 세지 않는다.
- **실패를 기록할 때 요청 주소를 싣지 않는다.** 검색 주소에 곡 제목이 들어 있어서, 그대로
  남기면 무엇을 찾았는지가 로그에 남는다.

## 교차 규칙

- **`audio-media`** — 번호는 곡에 딸린다. 곡을 지우면 번호도 함께 사라진다.
- **`secret-mode`** — 번호를 찾으려면 곡 제목이 외부 서비스로 나간다. 비밀 곡도 마찬가지다.
- **`device-transfer`·`backup`** — 번호는 곡에 딸린 값이라 곡과 함께 간다.
